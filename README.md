# Молодёжка · Среды

Сайт-приложение для молодёжного служения. В нём:
- план сред по месяцам;
- регламент каждой встречи по времени, где отмечены люди;
- задачи с отметкой людей;
- команда, форматы и идеи.

У каждого человека свой аккаунт. Сайт ставится на iPhone и Android как приложение, без App Store и APK.

Пока в `config.js` не вписаны ключи базы, сайт работает в **демо-режиме**: можно войти под любым тестовым человеком и посмотреть, как всё устроено.

## Запуск за 6 шагов (≈ 20 минут, бесплатно)

### 1. База данных (Supabase)
1. Зайди на **supabase.com** → **Start your project** → войди через GitHub.
2. **New project**. Название: `sredy`. Придумай и сохрани пароль базы. Регион: **Frankfurt (eu-central-1)**, он ближе всего.
3. Подожди 1–2 минуты, пока проект создаётся.

### 2. Таблицы и права доступа
1. Слева **SQL Editor** → **New query**.
2. Открой файл `supabase/schema.sql`, скопируй всё и вставь.
3. Нажми **Run**. Внизу должно появиться `Success`.

Скрипт создаёт таблицы, правила «кто что может менять» и стартовые данные с планёрки 16.11. В них есть встречи до конца января и регламент субботы 28.11. Скрипт можно запускать повторно, он ничего не удалит.

### 3. Вход по почте и паролю
1. Слева **Authentication** → **Sign In / Providers** → **Email**.
2. Проверь, что **Enable Email provider** включён.
3. **Выключи Confirm email** и сохрани.

Зачем это нужно: бесплатная почта Supabase отправляет всего пару писем в час и только участникам проекта. Без подтверждения по почте регистрация работает сразу. Чужие всё равно ничего не увидят, пока админ не впустит их в приложении.

### 4. Ключи в config.js
1. **Project Settings** (шестерёнка) → **Data API** (или **API**).
2. Скопируй **Project URL** в `supabaseUrl`.
3. Скопируй ключ **anon public** в `supabaseAnonKey`.

```js
supabaseUrl: "https://xxxxxxxx.supabase.co",
supabaseAnonKey: "eyJhbGciOi...",
```

Ключ `anon` можно выкладывать в открытый доступ. Данные защищают правила из шага 2, а не секретность ключа.

### 5. Сайт на GitHub Pages
1. На github.com → **New repository**. Имя: `sredy`, тип **Public**. Бесплатные GitHub Pages работают только с публичными репозиториями.
2. **Add file → Upload files** и перетащи все файлы и папки проекта: `index.html`, `app.js`, `styles.css`, `config.js`, `sw.js`, `manifest.webmanifest`, папки `icons`, `vendor`, `supabase`. Нажми **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source **Deploy from a branch**, ветка **main**, папка **/(root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/sredy/`.

### 6. Первый вход
1. **Ты регистрируешься первым** и автоматически становишься админом.
2. Отправь ссылку команде. Каждый жмёт «Регистрация» и вводит имя, почту и пароль.
3. Новые люди появляются у тебя во вкладке **Команда → Ждут подтверждения**. Нажми **Пустить**.
4. Там же поставь роль **Лидер** тем, кто будет вместе с тобой менять план сред.

## Кто что может

| Роль | Что может |
|---|---|
| **Админ** | Всё. Пускает новых людей, назначает роли |
| **Лидер** | Создаёт и меняет любые встречи и регламент, меняет любые задачи |
| **Участник** | Видит всё, ставит задачи, отмечает свои задачи. Меняет встречу и регламент, если он координатор этой встречи |

## Регламент встречи
Открой встречу → вкладка **Регламент**:
- Кнопка **Типовой регламент** заполняет пункты как у субботы: 17:30 зал → дежурные → 18:30 начало → 2 песни → молитва и слово → чай-пай → 21:00 конец.
- У каждого пункта есть время, что происходит и кто отвечает (**+ Отметить**). Если человека нет в приложении (например, гость), впиши имя в поле «Кто ещё».
- Кнопка **По времени** сортирует пункты.
- **Скопировать регламент для чата** даёт готовый текст для Telegram или WhatsApp.

Отмеченные люди видят свои пункты на главном экране («Ты в регламенте: 18:30 Начало, открывает») и во вкладке **Задачи → Мои**.

## Установка на телефон
- **iPhone:** открой ссылку в **Safari** → «Поделиться» → **«На экран Домой»**.
- **Android:** открой в **Chrome** → меню ⋮ → **«Установить приложение»** или «Добавить на главный экран».

## Если человек забыл пароль
По умолчанию кнопка «Забыли пароль?» не сработает, потому что бесплатная почта Supabase не пишет посторонним адресам. Есть два выхода:
- **Быстро.** Админ в Supabase открывает **Authentication → Users**, удаляет этого человека, тот регистрируется заново, и админ снова его пускает.
- **Навсегда.** Подключи бесплатный почтовый сервис (например, Brevo) в **Authentication → Emails → SMTP Settings**. Затем в шаблоне **Reset password** добавь строку `Код: {{ .Token }}`. После этого код для сброса будет приходить на почту.

## Как обновлять сайт
1. Меняешь файл на GitHub (карандаш → **Commit changes**).
2. После изменений увеличь номер версии в `sw.js` (строка `const CACHE`) и в `index.html` (`?v=4` → `?v=5`), чтобы телефоны сразу подтянули новую версию.
3. Список «Кто за что» меняется в `config.js` (блок `team`).

## Важно знать
- Бесплатный проект Supabase засыпает, если им никто не пользуется около недели. Включить его можно в панели Supabase кнопкой **Resume project**, данные сохраняются.
- Push-уведомлений пока нет: человек видит новые задачи с пометкой «Новая» и счётчик на вкладке «Задачи». Пуши можно добавить следующим шагом.
